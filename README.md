# AI Engineer Journey 🚀

A 17-week, hands-on journey from Python basics to production AI systems. I code every study day, track progress in sprints and solve DSA problems alongside.

**Timeline:** 13 Oct 2026 – 7 Feb 2027

## Roadmap
| Phase | Weeks | Focus |
|---|---|---|
| 1. Programming Foundations | 1–4 | Python, Git, NumPy, Pandas, SQL |
| 2. ML & DL Foundations | 5–7 | Machine Learning, PyTorch, Transformers |
| 3. LLM Engineering | 8–11 | LLM APIs, Prompting, Vector DBs, RAG, FastAPI |
| 4. Agentic AI & LLMOps | 12–14 | LangChain, LangGraph, Multi-Agent, MCP, Evals |
| 5. Production | 15–17 | Fine-tuning, Docker, CI/CD, AWS, Capstone |
